# Aniversário de 15 anos ( Site para Eventos )

Este projeto é um site completo para a celebração de um aniversário de 15 anos, criado com o objetivo de centralizar informações importantes para os convidados e tornar a experiência mais interativa e prática.  

## **📋 Funcionalidades**
### **Landing Page**
- **Informações do Evento:**  
  - Local da festa: endereço e horário.  
  - Tema da festa e vestimenta sugerida.  
- **Convite Digital:** Um design especial com a temática do evento.  
- **Contagem Regressiva:** Temporizador dinâmico indicando o tempo restante até o evento.  
- **Presentes:** Informações para presentes em formato de PIX ou depósito diretamente para a aniversariante.  
- **Confirmação de Presença (RSVP):** Um formulário interativo para os convidados confirmarem presença.  

### **Gestão da Lista de Convidados**
- Utilização de um arquivo `.txt` para armazenar e manipular os dados da lista de convidados.  
- Integração com JavaScript para leitura e atualização dinâmica da lista.  


## **🔧 Tecnologias Utilizadas**
1. **HTML5:** Estruturação das páginas com elementos semânticos.  
2. **CSS3:** Estilização personalizada para um design elegante e alinhado ao tema da festa.  
3. **Bootstrap:**  
   - Layout responsivo para dispositivos móveis e desktops.  
   - Componentes pré-construídos como botões, formulários e cards.  
4. **JavaScript:**  
   - Contagem regressiva dinâmica.  
   - Validação de formulários e confirmação de presença.  
   - Manipulação de dados da lista de convidados.  

## **🎯 Objetivo**
O site foi desenvolvido para:  
- Centralizar todas as informações do aniversário de 15 anos em um único local.  
- Facilitar a interação dos convidados, permitindo confirmações de presença e envio de presentes de forma digital.  
- Proporcionar uma experiência moderna e interativa para a aniversariante e seus convidados.  

## **🚀 Aprendizados e Desafios**
- Integração de arquivos externos (.txt) para manipulação de dados com JavaScript.  
- Criação de um design temático e responsivo utilizando Bootstrap.  
- Implementação de funcionalidades interativas para melhorar a experiência do usuário.
